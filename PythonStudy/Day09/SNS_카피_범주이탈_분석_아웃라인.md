# SNS 홍보 문구 범주 이탈 분석 아웃라인

> 목적: 작성된 SNS 홍보 카피가 `가을맞이_감성텀블러_트렌드키워드_데이터셋.xlsx`(유사도_데이터셋 시트, 7개 카테고리·85개 키워드)의 범주를 벗어났는지 점검한다.

---

## 0. 입력

- **분석 대상 카피**: [여기에 검토할 SNS 홍보 문구 삽입]
- **참조 데이터셋**: 가을맞이_감성텀블러_트렌드키워드_데이터셋.xlsx → `유사도_데이터셋` 시트 (키워드 85개, 유사도점수, 등장카테고리)
- **7개 기준 카테고리**: 패션 / 컬러 / 일상_감성 / 홈라이프 / 카페_음료 / 여행 / 브랜드_감성카피

## 1. 키워드 커버리지 매칭

- 카피를 명사·해시태그 단위로 분해
- 데이터셋 85개 키워드와 정확일치·부분일치 대조
- 출력: 매칭된 키워드 목록, 매칭률(%), 유사도 상위 10위 키워드 포함 여부

## 2. 카테고리 분포 확인

- 1단계에서 매칭된 키워드를 7개 카테고리에 재매핑
- 카테고리별 등장 횟수/비중 산출
- 출력: 카테고리 커버리지 표 (등장 O/X, 비중 %), 특정 카테고리 쏠림 또는 누락 여부 — 특히 `카페_음료`(제품 본연 맥락) 누락 여부는 별도 표시

## 3. 벡터 유사도 스코어링

- 기존 방식 재사용: 문자 n-gram TF-IDF 유사도 + 카테고리 동시출현 코사인 유사도 (0.5:0.5)
- 카피 전체 문장을 하나의 문서로 취급해 목표 문구("가을맞이 감성 텀블러") 및 7개 카테고리 벡터와 유사도 계산
- 판정 기준(예시): 데이터셋 내 최하위 키워드 유사도 점수 미만 → "이탈 의심" 플래그

## 4. 코퍼스 외 이탈어 탐지

- 카피 단어 중 7개 카테고리 코퍼스에 전혀 없는 단어 추출
- 이탈어를 다시 두 유형으로 분류: (a) 신선한 신조어/트렌드어 후보, (b) 주제 무관 단어
- 출력: 이탈어 리스트 + 유형 태그

## 5. 정성 체크리스트 (수치로 안 잡히는 부분)

- [ ] 스타벅스 톤앤매너(따뜻함/감성/절제된 톤) 일치 여부
- [ ] 과장·근거 없는 표현 여부
- [ ] 브랜드명/시즌/제품명 정확성
- [ ] CTA(행동 유도 문구) 존재 여부

## 6. 최종 산출물 포맷

| 항목 | 내용 |
|---|---|
| 적합도 종합 점수 | 0~1 (3단계 벡터 유사도 기준) |
| 매칭 키워드 | 목록 + 개수 |
| 카테고리 커버리지 | 7개 중 몇 개 충족 |
| 이탈 후보 단어 | 목록 + 유형 |
| 정성 체크 결과 | 체크리스트 통과 여부 |
| 종합 판정 | 적합 / 부분 이탈 / 이탈 (기준선 명시) |
